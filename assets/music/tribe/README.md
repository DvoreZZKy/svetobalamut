TRIBE uses a separate music loader and never falls back to the chaos playlist.

Verified candidate (not yet bundled): “Dark Cavern Ambient” by Paul Wortmann, CC0, OpenGameArt:
https://opengameart.org/content/dark-cavern-ambient

The page offers two OGG versions; version 002 is described as a continuous loop.
Place the chosen licensed OGG/MP3/WAV file in this folder. The game will load one file from here.
